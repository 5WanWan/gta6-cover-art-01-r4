Turn your photo into a GTA 6-style comic cover art poster — multi-panel comic layouts, bold poster lettering, Vice City sunset and neon grades. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

[Make GTA 6 Cover Art on make.fun](https://make.fun/bounty/gta6-cover-art-01)

## Run

Open `app/index.html` in a browser (or serve the `app/` folder with any static server), upload a photo, pick a layout and a grade, then export a PNG in 1080x1080, 1080x1350, or 1920x1080.
